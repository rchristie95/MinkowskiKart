Download version_1.9

Working builds are available for Windows, macOS, Linux, and Android. The exact Windows x64 release archive passes integrity, extraction, required gameplay-data and asset checks, and a 44-second headless race-initialisation smoke test.

Download for Windows Release page

Recommended starting point

Windows x64

  1. Download the 1.09 GB release archive.
  2. Verify its SHA-256 digest if possible.
  3. Extract the complete archive to a writable folder. Do not run it from inside the zip.
  4. Open the extracted folder and run run_game.bat.
  5. Configure keyboard or gamepad input under Options → Controls.
MinkowskiKart-version_1.9-win.zip

Verification

What the automated test proves

The exact published archive matches GitHub's SHA-256 digest, passes CRC and extraction checks, contains the x64 executable plus required data and assets, and initialises a two-kart Möbius Trip race for more than 44 seconds without an error or crash marker.

The publication workflow adds a second archive-level check so future uploads are extracted and inspected exactly as players receive them.

The published archive predates the workflow fix that adds a root copy of COPYING; the licence is available in the source repository and future Windows packages include it. The executable is currently unsigned. A graphical launch was not independently repeated because Windows Defender blocked the hidden PowerShell launch command; the safe direct headless test passed, and the game executable itself was not the detected resource.

Requirements

Known and unknown

No minimum desktop CPU, GPU, memory, storage, or operating-system version has been established by a reproducible test matrix.

Enhanced track tessellation requires desktop GLSL 4.00+ or OpenGL ES GLSL 3.20+. Use the standard clipping mode if the enhanced mode is unavailable.

Storage: allow substantially more space than the compressed download size for extraction. Exact installed-size guidance has not yet been measured.

Source build

Build the exact revision
