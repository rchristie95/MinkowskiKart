# Meshy Retextured Assets

This folder contains the 25 Meshy retextured GLB assets plus their downloaded PBR texture maps.

Each asset was retextured with a shared style prompt:

`low-poly arcade particle collider demolition derby, flat saturated colors, emissive cyan magenta gold physics markings, clean overhead readability, simple game asset textures`

The Blender scene imports these files into the `MESHY_RETEXTURED_VISIBLE_ASSETS` collection. The older `MESHY_IMPORTED_VISIBLE_ASSETS` collection is hidden, and the `MESHY_PROXY_*` objects remain as wireframe collision/layout helpers.
