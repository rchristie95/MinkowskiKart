# Security policy

## Supported versions

Minkowski Kart is experimental software. Security fixes target the latest public release and the current `main` branch when feasible; older releases are not maintained on a fixed schedule.

## Report a vulnerability privately

Do not open a public issue for a vulnerability that could expose players, server operators, credentials, or build infrastructure.

Use GitHub's **Report a vulnerability** form on the repository's Security tab:

<https://github.com/rchristie95/MinkowskiKart/security/advisories/new>

Include the affected version or commit, platform, reproduction steps, impact, and any suggested mitigation. Please avoid collecting or sharing other people's personal data and do not test against systems you do not own or have permission to assess.

Ordinary crashes, gameplay defects, and non-sensitive build failures should use the public [issue tracker](https://github.com/rchristie95/MinkowskiKart/issues).
