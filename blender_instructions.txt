High-level process:
1. Extract each Meshy OBJ zip to a temporary folder.
2. Open Blender from:
   C:\Program Files\Blender Foundation\Blender 5.1\blender.exe
3. Import the Meshy model as OBJ with its textures/materials.
4. Resize/orient the mesh so it roughly matches the original STK asset it replaces.
5. Apply transforms in Blender so scale/rotation are baked into the export.
6. Export the cleaned mesh through the STK Blender exporter to .spm.
7. Copy the exported .spm into:
   C:\Users\robso\OneDrive\Desktop\PersonalGames\MinkowskiKartGithub\stk-assets\models
8. Update STK XML/code to point at the new .spm asset.

- The Calabi-Yau pickup height was later adjusted in code in src\items\item.cpp.
- The cat is used both as the floating super-position marker mesh and as the front-mounted cat attachment.

Harmonic-oscillator (replaces mass-spike / anchor):
- Goal: a single combined mesh of a "dumbbell on a spring" mounted behind the kart.
- Import both Meshy OBJs into one Blender scene:
    * thick_suspensi* (spring)
    * thick_strongma* (dumbbell)
- Align the spring along the local Z axis (STK attachment frame: +Y up, -Z back).
  The attachment is positioned by code at roughly (0, highestPoint*0.35, -kartLength*0.55),
  so size the combined rig to fit a kart-sized bounding box (~0.8 m long, ~0.4 m tall).
- Anchor the spring at the rear of the kart; put the dumbbell at the free end.
- Apply transforms (Ctrl+A -> All Transforms) so scale/rotation bake in.
- Join both meshes into one object (Ctrl+J) so it exports as a single .spm.
- Export via the STK Blender exporter to:
    C:\Users\robso\OneDrive\Desktop\PersonalGames\MinkowskiKartGithub\stk-assets\models\harmonic-oscillator.spm
  The placeholder file currently in that folder is just a copy of anchor.spm and will
  be overwritten by the real export.
- The oscillation is driven by src\items\attachment.cpp (m_osc_pos animates the whole
  attachment node along +/- local Z). The dumbbell therefore does not need its own
  bone/animation - moving the entire mesh is enough.
