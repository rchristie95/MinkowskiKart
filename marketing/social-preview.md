# Social preview hand-off

The finished 1280 × 640 card is at:

`docs/assets/minkowski-kart-social-preview.png`

It uses the genuine in-game `mobius_race_hud.png` capture with a crop, readability treatment, and the exact text “Minkowski Kart” / “Relativistic Kart Racing.” It contains no platform logos or invented gameplay elements.

The website already references it in Open Graph and Twitter/X metadata. A copy is included with the itch.io package at `marketing/itch/minkowski-kart-social-preview.png`.

## Set the GitHub repository social preview

GitHub does not expose this setting through the available repository API.

1. Open <https://github.com/rchristie95/MinkowskiKart/settings> while signed in with admin access.
2. In **General**, scroll to **Social preview**.
3. Choose **Edit** and then **Upload an image**.
4. Upload `docs/assets/minkowski-kart-social-preview.png`.
5. Save and confirm the repository card shows the title at thumbnail size.

## Use on itch.io

After creating the itch.io project, upload `marketing/itch/minkowski-kart-social-preview.png` as the social/share image when the project theme editor offers that field. Keep the genuine gameplay screenshots as the page gallery rather than describing the social card as an untouched screenshot.
